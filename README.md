# Arrays in C#

## 📖 Overview

This project demonstrates the fundamental concepts of Arrays in C# using simple and beginner-friendly console application examples. Each array concept is implemented in a separate class to make learning easy and organized.

---

## 📚 Topics Covered

- Array Declaration
- Array Traversal
- User Input Array
- Single-Dimensional Array
- Multi-Dimensional Array
- Jagged Array
- Array Methods (Length, Sort, Reverse)
- Array Sorting

---

- C#
- .NET 10
- Visual Studio 2022
- Git
- GitHub

```text
Program.cs

```

---

## 🎯 Learning Outcomes

- Understand how arrays store multiple values.
- Access array elements using loops.
- Read array values from user input.
- Work with multi-dimensional and jagged arrays.
- Use built-in array methods like Length, Sort, and Reverse.
- Improve C# programming fundamentals.
